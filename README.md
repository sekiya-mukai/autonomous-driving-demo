# Autonomous Driving Demo

A simple Adaptive Cruise Control (ACC) and Collision Detection simulator written in C++17.

## Features

- Adaptive Cruise Control
- Collision Risk Detection
- Modern C++17
- CMake Build System

## Project Structure

.
├── include/
├── src/
├── test/
├── docs/
└── CMakeLists.txt

## Build

```bash
mkdir build
cd build
cmake ..
make


## Run
    ./autonomous_demo

## Example Output
    Target Speed : 50 km/h
    Collision Risk : true
